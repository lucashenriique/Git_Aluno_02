# 🚀 Como Enviar Arquivos Locais para o GitHub

Este guia rápido e prático vai te ensinar como pegar um projeto ou arquivos do seu computador e enviá-los para um repositório no GitHub usando o Git.

---

## 📋 Pré-requisitos

Certifique-se de ter os seguintes itens instalados no seu computador:
1. **Git** ([Baixe e instale aqui](https://git-scm.com/))
2. Uma conta no **GitHub** ([Acesse aqui](https://github.com/))

---

## 🛠️ Passo a Passo

### 1. Configurar o Git (Apenas na primeira vez)
Se você acabou de instalar o Git, configure seu nome de usuário e e-mail (os mesmos da sua conta do GitHub):
```bash
git config --global user.name "Seu Nome"
git config --global user.email "seu-email@example.com"
